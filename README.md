# ご飯のおとも MVP v14

「気になったお店を、忘れない。」

## 目的
SNSやWebで見つけた気になるお店を保存し、あとからエリアごとに見返せるお店管理アプリ。

主な保存導線：
**TikTok / Instagram / Web → 共有 → ショートカット「ご飯のおとも」→ アプリ**

保存時の入力をできるだけ減らし、必要な情報はあとから補足・編集する方針。

## 現在の機能
- ホーム
- 検索
- お店の追加
- 地図
- マイページ
- エリアごとの店舗一覧
- 🔵 行きたい / 🔴 行った
- 店舗詳細
- 価格帯の自由入力
- 評価・メモ
- 共有URLの受け取り
- TikTok共有URLの取り込み
- ローカル保存

## 下部ナビゲーション
順番は固定：
**⌂ ホーム｜🔍 検索｜＋｜🗺️ 地図｜👤 マイページ**

5項目を均等幅で配置し、アイコンを大きめに表示。

## 情報抽出
重要項目：
1. 店名
2. 住所
3. アクセス
4. 営業時間
5. 定休日
6. 価格帯
7. ジャンル

### v14の方針
- 住所・アクセス・営業時間・価格を別項目として扱う
- 「・アクセス」「［営業時間］」などが同じ行に続いても住所へ巻き込まない
- 営業時間は時間だけを抜き出さず、**曜日＋時間を含むブロック全体を保持**
- 例：月木 11:00〜20:00 / 金土 11:00〜22:00 のような曜日別情報を欠落させない
- 保存時に情報を勝手に短縮しない
- 抽出できない項目は空欄のまま、後から補足可能

## TikTok共有
iPhoneでは、
**TikTok → 共有 → ショートカット「ご飯のおとも」 → アプリ**
の橋渡し方式を使用。

- `index.html` — アプリ本体
- `manifest.webmanifest` — PWA設定

- `README.md` — プロジェクト説明

## 開発方針
「検索してお店を探す」より、
**気になったお店を保存して、エリアごとに広い視点で見返す**
ことを中心にする。

目標は、
**「ここ気になってたんだよね、行かない？」までの時間を短くすること。**
