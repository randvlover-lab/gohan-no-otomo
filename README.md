# ご飯のおとも — MVP v5

「気になったお店を、忘れない。」ためのスマホ向けMVPです。

## 今回の追加
- TikTokなどから共有されたURLを受け取る導線を維持
- TikTok URLならTikTok公式oEmbedから投稿情報の取得を試行
- 取得できたタイトルから店名候補を自動入力
- 取得できたサムネイルを保存候補として表示
- 投稿テキストから住所・営業時間・価格帯を拾える場合は自動入力
- 情報取得に失敗してもURLを保持して保存可能
- 店名未取得でも「店名未設定」で保存でき、あとから補完可能

## これまでのMVP機能
- ホーム：エリア中心 + 最近保存したお店
- エリア → 店舗一覧
- 絞り込み：すべて / 行きたい / 行った
- 並び順：保存が新しい順 / 古い順
- 店舗詳細：住所・営業時間・価格帯・地図・評価・メモ
- 🔵 行きたい / 🔴 行った の切り替え
- 手動追加
- 検索
- localStorage保存
- PWA manifest + Share Target の土台

## 注意
TikTok公式oEmbedで取得できるのは投稿のタイトル、投稿者、サムネイルなどの投稿情報です。店名・住所・営業時間が必ず取得できるわけではありません。
そのため「自動取得できるものは入れる → 足りないものは後から補完する」という設計にしています。

GitHub PagesなどHTTPS環境で公開して、現在作っているiPhoneショートカットからURLを渡してテストしてください。
