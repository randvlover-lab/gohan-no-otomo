# ご飯のおとも — MVP

スマホ向けの動くMVPプロトタイプです。

## 入っている機能
- ホーム：エリア中心 + 最近保存したお店
- エリア → 店舗一覧
- 絞り込み：すべて / 行きたい / 行った
- 並び順：保存が新しい順 / 古い順
- 店舗詳細：住所・営業時間・価格帯・地図・評価・メモ
- 🔵 行きたい / 🔴 行った の切り替え
- 手動追加（あとから編集する前提）
- 検索
- localStorage保存（ブラウザを閉じてもデータを保持）
- PWA manifest + Share Target の土台

## 試し方
index.html をブラウザで開くだけでも、基本UIを触れます。

### 「SNS → 共有 → ご飯のおとも」の本番テスト
Share Target はインストール可能なWebアプリとしてHTTPS環境で動かす必要があります。
このMVPには `manifest.webmanifest` の share_target を入れてあります。

本番版では、共有されたSNS投稿のURL/本文から
「店名・住所・営業時間」などを自動抽出する処理を追加します。

## 注意
このMVPは「仕様確認・操作感確認」が目的です。
SNSごとの情報抽出、ログイン、クラウド同期、正式なiOS/Androidアプリ化は次段階です。
